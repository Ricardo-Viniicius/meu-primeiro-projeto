# meu-primeiro-projeto
# 🧠 Projeto: Quiz Interativo - Web Básico

Este é o meu primeiro projeto oficial como desenvolvedor em formação. Trata-se de um Quiz interativo criado para testar conhecimentos e, principalmente, consolidar meus estudos iniciais na web.

## 📝 Sobre o Projeto
O objetivo deste projeto foi aplicar os conceitos fundamentais de estruturação e estilização. Através dele, pude praticar como organizar informações de forma hierárquica e como criar uma interface amigável para o usuário.

## 🛠 Tecnologias Utilizadas
- **HTML5:** Utilizado para a marcação semântica dos cards de perguntas e opções de resposta.
- **CSS3:** Focado na criação de um layout limpo, uso de cores para feedback visual e responsividade básica.

## 🚀 O que eu pratiquei:
- Estruturação de formulários e botões.
- Alinhamento de elementos com CSS (Box Model).
- Estilização de estados.
- Organização de arquivos e versionamento com Git.
